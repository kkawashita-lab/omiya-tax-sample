## GitHub Pagesへの公開

1. Publicのリポジトリを作成します（例：omiya-tax-sample）。
2. このフォルダの中身をリポジトリ直下へアップロードします。
3. Settings > Pages > Source: Deploy from a branch を選びます。
4. Branch: main、Folder: /(root) を選び、Saveします。
5. Pages画面に表示されたURLへアクセスします。

画像とページリンクは相対パスへ調整済みです。
独自ドメインや username.github.io 形式でも、通常のプロジェクト用URLでも利用できます。
外部ライブラリやビルド処理、サーバー処理は必要ありません。
